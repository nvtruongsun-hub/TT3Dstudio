Quy Trình Quản Trị Serverless Trên GitHub Pages

Vì website chạy tĩnh trên GitHub Pages không cần máy chủ (Serverless), hệ thống hoạt động thông minh qua 2 tầng lưu trữ:

1 Tầng 1: Thao tác & Lưu ngay (Trình duyệt)

Khi bạn thêm, sửa, xóa sản phẩm hoặc chỉnh bảng giá, dữ liệu lưu ngay lập tức vào localStorage. Tab index.html sẽ tự động cập nhật ngay trên máy bạn.

2 Tầng 2: Xuất file products.json lên GitHub

Bấm nút "Xuất file products.json" để tải file về máy, sau đó commit file này lên GitHub repository. Tất cả khách truy cập từ mọi thiết bị khác sẽ nhìn thấy danh mục mới vĩnh viễn!
